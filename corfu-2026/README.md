# Κέρκυρα 2026 — Λίστα μετακίνησης & διαμονής

**Σελίδα:** https://webappngdsib.github.io/NGLG-Grand-Secretary/corfu-2026/

## Τι υπάρχει ήδη
- Η HTML σελίδα, αναζήτηση, καταμέτρηση, εκτύπωση και CSV.
- Αρχικό `attendees.json` με δύο επιβεβαιωμένες δηλώσεις.
- Στήλη «Σχόλια» για τον πιθανό συγκάτοικο του Φιλίππου Δημητρίου (δεν δημιουργείται νέα δήλωση).
- Ο HTML client διαβάζει το JSON χωρίς κωδικό ή Gmail πρόσβαση.

## Ενεργοποίηση δίωρου και κουμπιού άμεσης ενημέρωσης (μία φορά)
1. Συνδεθείτε στο https://script.google.com/ με **grand.secretary@nglgreece.gr**.
2. Δημιουργήστε νέο έργο Apps Script και επικολλήστε το περιεχόμενο του `Code.gs`.
3. Στο **Project Settings → Script Properties** δημιουργήστε `GITHUB_TOKEN`, με fine-grained GitHub token, repository `webappngdsib/NGLG-Grand-Secretary`, permission **Contents: Read and write**. Μην βάζετε token σε HTML ή στο repo.
4. Επιλέξτε `testCorfuSync` για προεπισκόπηση των δηλώσεων.
5. Επιβεβαιώστε την εξουσιοδότηση δημοσίευσης των ονομάτων συμμετεχόντων και έπειτα εκτελέστε `setupCorfuSync` (Gmail/UrlFetch authorization).
6. Στο Apps Script → Triggers επαληθεύστε τον trigger `syncCorfu2026`, **every 2 hours**. Τα GitHub Pages δημοσιεύουν τις ενημερώσεις μετά από κάθε commit.
7. **Deploy → New deployment → Web app**: **Execute as: Me** (grand.secretary@nglgreece.gr) και **Who has access: Only myself**. ΠΟΤΕ «Anyone»: αυτό το script μπορεί να διαβάζει Gmail και να γράφει στο GitHub.
8. Αντιγράψτε το URL του Web App (μορφής `https://script.google.com/macros/s/.../exec`) στο `web_app_url` του `sync-config.json` και κάντε commit στο GitHub. Δεν μπαίνει κανένα token ή password στο JSON.
9. Πλέον το κουμπί **«↻ Άμεση ενημέρωση από Gmail»** ανοίγει το προστατευμένο Web App και εκτελεί τον συγχρονισμό. Η ιστοσελίδα παρακολουθεί το JSON και αναγνωρίζει όταν δημοσιευτούν νεότερα δεδομένα.

Αν δεν έχει ενεργοποιηθεί το Apps Script, η ιστοσελίδα λειτουργεί με τις δύο **στατικές, ελεγμένες** δηλώσεις αλλά **δεν** ενημερώνεται αυτόματα.

## Κανόνες
- Ελέγχονται αρχικά μηνύματα με ακριβές πρόθεμα θέματος `ΜΕΤΑΚΙΝΗΣΗ ΚΕΡΚΥΡΑ` ή `ΚΕΡΚΥΡΑ ΜΕΤΑΚΙΝΗΣΗ`, ακολουθούμενα από ονοματεπώνυμο.
- Απαιτείται θετική διατύπωση συμμετοχής στο σώμα. Εξαιρούνται απαντήσεις, άσχετα θέματα, αρνήσεις.
- Οι δηλώσεις δωματίου δεν συνιστούν επιβεβαίωση κράτησης. Η στήλη «Σχόλια» διατηρείται σε επόμενους συγχρονισμούς.
- **Προσοχή:** οι διευθύνσεις email, τα ονόματα, τα αξιώματα και τα σχόλια είναι δημόσια στην τρέχουσα GitHub Pages εγκατάσταση. Δεν δημοσιεύονται τηλέφωνα ή το πλήρες περιεχόμενο των email.
- **Προσοχή:** τα GitHub Pages του υφιστάμενου repo είναι δημόσια. Εάν η λίστα πρέπει να είναι εσωτερική, απαιτείται φιλοξενία με έλεγχο πρόσβασης πριν διανεμηθεί ο σύνδεσμος.

## Δήλωση με ονοματεπώνυμο στην υπογραφή
Αν το θέμα είναι ακριβώς `ΜΕΤΑΚΙΝΗΣΗ ΚΕΡΚΥΡΑ`, η αναγνώριση μπορεί να αναζητήσει ονοματεπώνυμο από ρητή υπογραφή με τίτλο π.χ. `Σεβ. Αδ. Ροής Σπυρίδων`. Η ύπαρξη του ονόματος **δεν σημαίνει** αυτόματη πιστοποίηση αξιώματος: ο έλεγχος γίνεται ξεχωριστά έναντι της Επετηρίδας.
